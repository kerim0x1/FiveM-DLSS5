# FiveM-DLSS5 1.0.0

One zip. Drop it into FiveM `plugins`. Done.

## Install

1. Close FiveM completely.
2. Download `FiveM-DLSS5-1.0.0-plugins.zip` below.
3. Copy **the contents** here:

```
%LOCALAPPDATA%\FiveM\FiveM.app\plugins
```

Win+R → `%LOCALAPPDATA%\FiveM\FiveM.app\plugins` → Enter.

4. Start FiveM. Press **Home**.
   - Lumenite Kernel on, DLSS 5 Feed under it
   - Keys **1 / 2 / 3 / 4** = Balanced / Quality / High / Ultra

Do not put this next to Steam `GTA5.exe`. FiveM only loads `plugins\d3d11.dll`.
