# Security

Report vulnerabilities to **contact@kerim0x1.com**.

Do not open a public issue for a working exploit.

This repository ships PowerShell you can read. There is no compiled
installer and no download from a `github.io` page.

Never run a zip named `DLSS5-Feeder-*.zip` that did not come from
https://github.com/jlrouzies-fr/DLSS5-Feeder/releases
